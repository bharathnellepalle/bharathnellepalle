### 🚀 Featured project

**[OSS Notice File Generator](https://github.com/bharathnellepalle/oss-notice-file-generator)** — a web-based open-source-compliance tool.
Give it a CSV/JSON list of your dependencies and it fetches each package's source
(Git, npm, PyPI, Maven, NuGet, crates, conda, or purl), runs
[ScanCode Toolkit](https://github.com/nexB/scancode-toolkit) to extract copyright
notices, resolves license texts from the SPDX catalog, and produces a
Microsoft-style `THIRD_PARTY_NOTICES.txt` — with real-time scanning, notice-file
repair, and merge tools.

`FastAPI` · `React` · `TypeScript` · `WebSockets` · `ScanCode` · `SPDX`
