### 🚀 What I've been building

> **[OSS Notice File Generator](https://github.com/bharathnellepalle/oss-notice-file-generator)** — a web app that reads a list of your open-source dependencies, fetches each package's source (Git, npm, PyPI, Maven, NuGet, crates, conda, or purl), runs [ScanCode Toolkit](https://github.com/nexB/scancode-toolkit) to pull the real copyright notices, and generates a Microsoft-style `THIRD_PARTY_NOTICES.txt` — with live scanning, notice-file repair, and merge tools.
>
> `FastAPI` · `React` · `TypeScript` · `WebSockets` · `ScanCode` · `SPDX`
